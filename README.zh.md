# rmc-memory

[English](README.md) | 中文

**关系记忆引擎，为跨会话智能体组织可追溯的记忆。**

RMC 释义为 Relational Memory Core（关系记忆核心）。项目名称为 `rmc-memory`，计划使用 Python 导入名 `rmc_memory`。

## 当前状态

本仓库处于契约设计阶段。已有双语文档和文档检查工具；独立记忆引擎尚未实现，不提供安装使用承诺。`0.1.0` 是计划首版，不是已发布版本。包名可用性、许可证、权利主体及公开托管地址仍需发布前确认。

## 产品边界

目标是基于 Python 标准库和 SQLite 的嵌入式图记忆库：由宿主决定写入哪些节点和关系，由引擎组织存储与检索，由宿主模型生成回答。它不是大模型、完整智能体平台、知识库抓取器或机器人控制系统。

核心目标是无第三方运行时依赖、默认不联网。可选匹配策略不等于默认启用 embedding；测试 mock 不具备语义能力。当前没有独立包的性能、隔离或评测成绩可供承诺。

## 本地文档开发

要求 Python 3.10 或更新版本。从仓库根目录执行：

```sh
python3 -m unittest discover -s tests -v
python3 scripts/check_docs.py
```

这些命令验证文档工具与配对一致性，不验证尚未实现的记忆引擎。代码、API和行为文档应在同一变更中更新，先明确验收条件，再以真实公开入口验证实现。

## 沟通与发布

本阶段通过现有协作渠道审核本地文档，不要求 Discord 或其他需要额外跨境网络访问工具的社区平台，也不编造企业邮箱、群码或支持渠道。公开发布前确认可访问的反馈入口；核心使用不得依赖社区账号或在线文档站。
