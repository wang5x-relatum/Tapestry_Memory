[English](project-status.md) | 中文

## 当前状态

`tapestry-memory` 处于阶段 2，是一个独立的 Python 库：默认离线、按 namespace 隔离、基于 SQLite 的图记忆引擎，运行时无第三方依赖。项目由 MetaRelatum（越迹科技（宁波）有限公司）维护，采用 Apache-2.0 许可证。

当前公开包提供图存储、有向关系、有界确定性 BFS 检索、来源元数据往返、逻辑删除、事务回滚和数据库重开。认证、同意、写入策略、冲突裁决、来源时效、回答生成和动作安全仍由宿主应用负责。

## LongMemEval 历史证据

[LongMemEval 历史评估](evaluations/longmemeval.zh.md) 单独记录了一项独立建库前的实验：90 题答对 73 题，准确率 81.11%。由于它早于独立包，且缺少完整的可复现记录，只能作为历史佐证，不能作为当前 wheel 的 benchmark 结果、性能保证或当前包的直接成绩。

## 边界与后续

本仓库不宣称自动关系抽取、语义真值验证、冲突裁决、同步、分布式运行、任意规模性能或生产就绪。后续发行决策应继续区分包本身的行为、历史实验和更广义的 Relatum 研究组件。
