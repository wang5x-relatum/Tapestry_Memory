# v0.1 契约

[English](v0.1-contract.md) | 中文

状态：面向 `tapestry-memory` 本地实现的阶段 2 行为契约，目标版本为 0.1.0。下述公开 API 是已约定的实现契约，不代表验收测试或产物验证已通过。本文是行为契约真源；源项目成绩不能替代独立包验收。编辑后的双语文档仍待人工复核。

## 范围

核心覆盖嵌入式图记忆：节点、有向边、命名空间、持久化、有界关系检索与逻辑删除。运行时使用 Python 3.10+、标准库和 SQLite，无第三方运行时依赖，默认不联网，不导入 Relatum 内部模块。包不包含宿主的人格、价值策略、模型调用、对话原文回捞或机器人动作编排。

阶段 2 不做自动关系抽取、自动矛盾裁决、多设备同步、分布式服务、任意规模保证、500 字符截断、GDPR 彻底删除及默认 embedding。下述 API 不承诺匹配回调或语义排序。

## 数据与身份

公开类型从 `tapestry_memory` 导入。`Node` 包含 `id`、`content`、`metadata`、`created_at` 和 `weight`。`Edge` 包含 `source`、`target`、`relation`、`weight`、`count` 和 `created_at`。ID 为自动生成的 UUID4 字符串，不提供调用方指定节点 ID 的 API。节点主键身份是 `(namespace, id)`，绝不包含内容哈希。同内容在同域与跨域均产生独立节点。

content 是字符串，允许空字符串和超过 500 字符的字符串，不截断。weight 接受非负整数或浮点数，不接受布尔值，并转换为有限浮点数；非有限值及转换溢出抛出 `ValueError`。边的 count 是 `1..2**63-1` 范围内的整数（有符号 64 位范围），不接受布尔值。created_at 使用带微秒和 `+00:00` 的 UTC ISO 8601 格式；更新保留创建时间。边在作用域内按有向 `(source, target, relation)` 唯一；重复写入替换 weight 和 count，不做累加，保留创建时间。

metadata 是严格原生 JSON 值组成的字典：键为字符串，值允许字典、列表、字符串、布尔值、整数、有限浮点数和 null。metadata 参数为 `None` 时表示 `{}`。拒绝元组、集合、自定义值、循环引用及非有限浮点数。更新 metadata 是整份替换，不是合并。可选嵌套 `provenance` 在写入、数据库关闭重开、检索之间无损保留 JSON 值。不要求 `r:/c:` 格式，不自动打开来源文件或 URL，来源不等于真实性验证。

## 命名空间与删除

`MemoryStore(path=':memory:', *, namespace='default')` 为该存储实例固定只读命名空间。省略时选择 `default`；显式传入 `None`、空字符串、纯空白字符串或非字符串时抛出 `ValueError`。其他命名空间字符串原样保留，不裁剪空白。命名空间约束所有读写、起点查找、每次邻居扩展、边两端、结果、更新和删除。不提供隐式全局或共享域，也不提供命名空间删除 API。库级隔离不替代宿主身份认证与授权。

逻辑删除在当前命名空间内把节点及其关联边移出活跃图；已删除数据不得通过查询或遍历再次出现。如有包拥有的派生数据须删除，包内缓存须失效；阶段 2 不存在派生数据或缓存。删除边仅影响指定作用域内的有向三元组。其他命名空间保持不变。这是库接口层面的逻辑删除，不承诺物理介质擦除、外部原文删除、宿主日志删除、备份删除或 GDPR 彻底删除。

## 公开方法与变更语义

下列签名定义公开接口；`...` 表示省略的更新字段，不是应传入的值。省略的更新字段保持原值。

```python
MemoryStore(path=':memory:', *, namespace='default')
store.add_node(content, *, metadata=None, weight=1.0) -> Node
store.get_node(node_id) -> Node | None
store.update_node(node_id, *, content=..., metadata=..., weight=...) -> Node
store.delete_node(node_id) -> bool
store.add_edge(source, target, relation, *, weight=1.0, count=1) -> Edge
store.get_edge(source, target, relation) -> Edge | None
store.delete_edge(source, target, relation) -> bool
store.retrieve(seed_ids, *, top_k=10, max_depth=2,
               traversal_budget=1000) -> RetrievalResult
store.transaction()
store.close()
```

查询缺失项返回 `None`；删除缺失项返回 `False`。更新不存在的节点，或添加边时端点不存在、已删除或位于其他域，均抛出 `KeyError`。公开输入无效时抛出 `ValueError`。所有写入具有原子性。`transaction()` 将多次写入组成事务，失败时回滚；嵌套使用保存点，内层失败若被捕获，可仅回滚内层而保留外层写入。未捕获的外层失败回滚外层事务。将 `MemoryStore` 用作上下文管理器仅在退出时关闭连接；组合写事务须显式使用 `transaction()`，不是存储实例上下文管理器。

已提交数据须在重开同一文件数据库后保留。失败事务不得在重开后遗留部分节点、边或 metadata 更新。默认 `:memory:` 存储关闭后不承诺持久化；重开验证使用数据库文件。

## 有界确定性检索

`retrieve` 返回 `RetrievalResult`，包含 `nodes`（元组）、`visited_count`、`traversed_edges` 和 `budget_exhausted`。检索沿出边做有向广度优先遍历，不按 weight 排序，也不做五维评分。起点按输入顺序去重；有效起点在深度 0 纳入遍历。不存在、已删除和其他域的起点被忽略。邻居按目标 ID、再按 relation 的字典序排列。确定性指同一已存储图和有序起点输入产生相同遍历，不是独立生成 UUID 后顺序仍相同。

`top_k`、`max_depth` 和 `traversal_budget` 必须是大于等于零的整数，不接受布尔值；默认值依次为 10、2 和 1000。`max_depth` 限制扩展深度。`top_k` 仅限制返回节点数量，不限制遍历；`visited_count` 可以大于返回元组长度。遍历预算对每条检查过的边计数，包括指向已访问节点的边。`traversed_edges` 报告该数量。仅当预算阻止继续检查下一条符合遍历条件的边时，`budget_exhausted` 才为真；恰好达到数值上限但已无符合条件的边，不算耗尽。部分结果不得表示成穷尽遍历。隔离必须贯穿遍历，而非仅在最终结果过滤。

起点输入处理为 O(传入起点数量)，不计入边遍历预算；调用方须提供有限可迭代对象并自行限制其大小。`top_k=0` 仍遍历并计数，`max_depth=0` 不扩展，`traversal_budget=0` 仍纳入有效起点，但仅在存在可扩展出边时报告预算耗尽。

## 实施顺序与完成标准

| 阶段 | 产出 | 完成标准 |
| --- | --- | --- |
| 设计基线 | 双语场景、契约、文档规范 | 待审核项显式标注，检查器覆盖其承诺的机械规则 |
| 阶段 2 核心切包 | 独立包、存储与检索实现 | 标准库运行时，不导入 Relatum，默认离线，公共接口可运行 |
| 契约验收 | 单元与契约测试 | 跨域同内容、跨边遍历隔离、跨域删除隔离、回滚、来源往返和重开数据库均覆盖 |
| 阶段 2.4 产物验收 | wheel 和 sdist | 干净环境安装后运行示例；产物仅含允许文件，无数据库、密钥或内部材料。本地安装验证目前仅覆盖 wheel，不覆盖 sdist。 |
| 发布审核 | 许可证、版本、文档与评测记录 | 用户批准发布；发布的是已验证的同一份产物 |

本地核心实现不等于产物验收或发布。单元与契约测试结果须分别注明范围及数量，文档检查结果单独报告。本文记录要求，不记录已完成的测试运行。双语变更后保留过期哈希，等待人工复核；只有复核完成，才按现有文档规则为明确复核过的路径记录哈希。
